# חדר הלבשה

מעלים תמונה שלך ותמונה של בגד, ורואים את עצמך לובש אותו. אחר כך אפשר לשנות צבע, בד, הדפס, אורך, קו עליון וזווית (מאחור, מהצד), או לכתוב שינוי חופשי.

- הלבשה: FASHN Try-On v1.6 דרך fal.ai (כ-7.5 סנט לתמונה)
- עריכות: Nano Banana Edit דרך fal.ai (כ-4 סנט לעריכה)
- התמונות לא נשמרות בשרת.

## פריסה ב-Render (פעם אחת, כ-10 דקות)

1. נכנסים ל-[render.com](https://render.com) ומתחברים עם GitHub.
2. **New** ← **Blueprint**, ובוחרים את המאגר הזה. Render קורא את `render.yaml` לבד.
3. ממלאים שני ערכים כשהוא מבקש:
   - `FAL_KEY`: המפתח מ-[fal.ai/dashboard/keys](https://fal.ai/dashboard/keys)
   - `APP_PASSWORD`: סיסמה שתבחר לכניסה לאפליקציה
4. **Apply**. אחרי כמה דקות מקבלים כתובת כמו `https://fitting-room-xxxx.onrender.com`.
5. בטלפון: פותחים את הכתובת ← שיתוף ← "הוספה למסך הבית", והיא נפתחת כמו אפליקציה.

בתוכנית החינמית השרת נרדם אחרי 15 דקות בלי שימוש, והפתיחה הראשונה אחרי זה לוקחת כחצי דקה.

## הרצה מקומית

```bash
pip install -r requirements.txt
FAL_KEY=... APP_PASSWORD=... uvicorn main:app --port 8000
```

בלי `FAL_KEY` האפליקציה רצה במצב הדגמה ומחזירה את התמונה בלי שינוי.

## טיפים לתוצאה טובה

- תמונת גוף מלא, מלפנים, עמידה ישרה, תאורה אחידה, רקע לא עמוס.
- תמונת בגד ברורה: צילום מוצר על רקע חלק, או בגד על דוגמן.
- שינויים גדולים (אורך, קו עליון) עובדים הכי טוב אחד אחד.
- מבט מאחור ומהצד הוא הדמיה שה-AI משלים, כי יש רק תמונה אחת שלך.
